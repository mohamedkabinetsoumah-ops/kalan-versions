# Kalan — fichiers d'installation

Kalan est un logiciel de gestion d'établissement scolaire : élèves, inscriptions,
frais de scolarité, notes et bulletins, absences, documents.

Ce dépôt ne contient **que les fichiers d'installation** de Kalan. Il n'y a ici
ni code source, ni donnée d'aucune école.

## À quoi sert ce dépôt

Le Kalan installé dans une école vient y vérifier, quand son poste a Internet,
s'il existe une version plus récente. Il ne télécharge et n'installe rien sans
l'accord du directeur.

## Installer Kalan

1. Ouvrez la page [Releases](../../releases/latest).
2. Téléchargez le fichier `Kalan-Installation-<version>.exe`.
3. Lancez-le sur l'ordinateur qui servira de poste maître (Windows 10 ou 11).

Windows affichera « éditeur inconnu » : le fichier n'est pas signé.

Kalan fonctionne soixante jours sans clé d'activation. Passé ce délai, la
saisie est suspendue ; la consultation, l'impression et l'export restent
possibles et aucune donnée n'est effacée. La clé d'activation est remise par
le fournisseur.
